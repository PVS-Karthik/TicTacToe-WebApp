# Tic Tac Toe Web Application

## 🚀 Project Overview

A modern and interactive Tic Tac Toe Web Application developed using HTML, CSS, and JavaScript designed to provide an engaging two-player gaming experience. The application includes winner detection, game reset functionality, responsive design, smooth UI interactions, and real-time gameplay updates for an enjoyable user experience.

---

## ✨ Features

* Two Player Gameplay
* Winner Detection System
* Draw Match Detection
* Restart Game Functionality
* Interactive Game Board
* Responsive User Interface
* Smooth User Interaction
* Real-Time Game Updates
* Modern UI Design
* Lightweight Performance
